NIOLI ASSET DROP V1

This package is meant to be extracted into: public/nioli/

IMPORTANT:
- refs/ contains CANON REFERENCE SHEETS only. Do not use them as production UI art.
- brady/ contains individual transparent PNGs that can already be used by the app.
- countries/* folders are intentionally prepared but not filled with cropped production elements yet.
- The country reference sheets define the visual direction for each country and should guide future individual exports.
- Do not recolor, redraw, modernize, or apply sepia filters to Brady.

Canon countries included: JP, MX, CO, US, ES, CL, AR, KR, CR.
