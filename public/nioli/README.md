# Nioli Asset Drop V2

This pack contains production-oriented crops derived from the approved Nioli country master sheets, plus Brady core assets.

Important:
- `/public/nioli/refs/countries/` contains the full approved master sheets.
- Country assets under `/public/nioli/countries/<code>/` are cropped exports intended for integration/QA.
- Do not redraw or recolor Brady.
- Do not use Japan as fallback for other countries.
- Keep unknown countries on the generic/international fallback.
- Some cropped assets retain the master-sheet paper texture by design.
